ION is a black iPhone-inspired word/picture cloud with Inter and flat blue chess. Home is exactly Chess/Public/Private, fixed anchors, no creation, no startup shifting. Public is globally readable; Private requires its account; only the configured owner ID edits shared Chess. Exact realtime channels and atomic cross-space transfers remain authoritative. Each cloud allows 1,024 immediate children, enforced on add/move/copy/restore/transfer; total/nesting are independent. Private has an eight-color horizontal selection wheel; saved colors follow branches. No native app scrolling anywhere: SpatialViewport uses a transform pan/zoom camera, rules use fitted PagedText, menus/accounts use PageControls. Pictures only appear inside rule droplets, never their list. Top-left opens the current scope root; bottom Back stays. Undo deletion expires at original time+10 seconds, even after reload. Tactical has six levels including Pre-Beginner 0 (40ms/125nodes/depth1 and 50% random legal choice); Pass and Play deselects the engine. Signup is an explicit URL state and normalizes email at both API boundaries, never falls back to login. Recovery has compact email/code/password steps. Remembered accounts use HttpOnly device cookies and valid server sessions. Preserve C++ rule authority, saved games, swipe review, high-contrast pieces, reduced motion, compatible-only install and public/private authorization. Canonical docs: DESIGN.md and UX-CONTRACT.md.
