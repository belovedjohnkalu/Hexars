ION is a cloud-hosted, iPhone-themed app whose primary navigation is a recursive cloud of words and pictures. Root starts with a Hexagonal Chess image. Inside: Engines, Rules, Boards. Engines lists Tactical only; Rules has Gliński and McCooey; Boards opens pass-and-play directly with a compact variant choice. A node is a cloud to its children and a droplet of its parent. Size uses all descendants, normalized among visible siblings; ties/singletons are equal, zero stays readable. Users add private words or pictures through one long frosted bar. Per-browser capability protects server-persisted workspaces and private image storage. No sign-in/sync/deletion UI yet. Existing authoritative C++ chess rules and cloud computation are preserved. Do not claim Shafran or the other engines are implemented in this Floot app. Dark blue/black, self-hosted Inter, sparse large text, restrained glass and smooth reduced-motion-aware zoom. Preserve saved chess games and install compatibility behavior. Design and workflows: static/__dev/DESIGN.md, static/__dev/UX-CONTRACT.md. Architecture: static/__dev/notes/cloud-navigation.md.
