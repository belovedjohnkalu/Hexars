# ION 0.63 — Light theme, printed rhombi and named tiles

ION opens in a true light theme. The existing IL04A10 switches to persistent dark mode, with green/red active state and matching browser chrome. Images, videos and blue boards retain their actual colors. Legacy inversion preferences no longer invert the application.

## Cloud composition

Normal cloud pages, Rules, Time, Accounts, Controls, Safari, Journal and Tiles share an exact triangular-lattice mosaic. Adjoining 60°/120° rhombi use three printed planes, two decompositions and complete-face subdivisions. Labels and multimedia stay inside the face, and the polygon is its actual hit target. Whole-word wrapping, permanent ILs, permission checks and image inspection remain. Descendant characters alone determine relative type size; a long label reserves space without increasing its own font. Picture frames vary in size and contain the full image. Small pages initially fit the full composition; large pages support panning and zooming. Deletion repacks faces while retaining the camera, and an empty page remains centered.

Playable boards stay flat and large. Their surrounding action clouds, saved-game actions and temporary online chat clouds reuse the same printed-plane primitive. Blue cells and existing game rules, legal moves, history, sides and cell hitboxes remain authoritative.

## Tiles

Left input swipe creates a new tile, right revisits a tile and up opens Tiles. Tile names persist per account in the current device session and appear above the current header, shared by that tile's independent screens. Holding a tile offers Rename and Delete. Deleting a tile closes views only and retains the unsaved-media safeguard.

The assembly title, New Tile, Rename and Delete are functional clouds with permanent ILs and normal registered-dev hold-to-edit behavior. The three older tile function entries were soft-deleted before this request; only those explicitly requested entries were reactivated, preserving their identities. Unrelated tombstones were untouched. Tile functions use actual workspace actions and do not add a redundant Tiles entry to the ordinary Controls page. Split close buttons are excluded from screen-child height rules and remain 44px square.
