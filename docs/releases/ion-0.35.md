# ION 0.35 — Direct Time navigation and descendant character sizing

Signed-in Prices lists every paid catalog feature, including purchased and unaffordable ones. Regular product pages contain only the current Time amount and a Purchase word if published, pricing-ready, affordable and not already owned. Purchased pages retain the current price without redundant Open/Purchased/estimate/buyer controls; dev cost records and revision controls remain available. This price-catalog exception does not change hidden unaffordable features in chess navigation or server purchase/entitlement checks.

Time now contains Added, Spent and Balance directly. Their original functional IDs and ILs stay fixed. The Activity wrapper is hidden; legacy URLs redirect to Time. Existing children stored beneath Activity are projected into Time and normalized on their next ordinary write. Owner-added words remain; the shared owner-only editor still applies. Live totals retain one per-second projection only while Time is open, and spending still uses posted server balances.

Earn removes the duplicate Earning entry. How it works contains three actual paragraph clouds with permanent functional identities, using the existing organic canvas. The stable receive-name identity remains reserved. Receive instead lists incoming transfers/treasury payouts, excluding active-use issuance. Its latest requested empty state is exactly “Empty”; errors show retry rather than a false empty result. Filters apply before existing account-scoped cursor pagination. Spent's empty state has no Earn link.

Font percentages and magnitude refinements now depend only on Unicode characters in descendants' labels/text, at every depth. A node's own label/note, word count and synthetic image-word equivalents never increase its own font. Leaves tie regardless of label length. Cross-space metadata carries descendant character totals. Picture entry allowance remains 1,000 words per picture, separately from font sizing; unused branch word-weight calculations/response fields are retired.

Custom words in Controls remain visible on the normal Controls page, including owner editing. A hold context shows only permitted control actions; custom words and the add composer are omitted. Board Reset starts engine games as White with the normal White perspective, retaining engine/variant/level and the existing reset confirmation. Online reset remains unavailable.

Validation: clean hosted TypeScript; targeted hierarchy, pricing, functional-ID, Time-total, rules/gate, layout, transfer and game-hook suites pass. The browser suite covers signed-in catalog visibility, owned/unaffordable/affordable price pages, quote failure and retry without confirming a transaction, direct totals, Controls filtering, paragraph clouds, Receive/Spent states, phone presentation, and a real anonymous Universal game reset from Black to White. No financial balances, cost estimates, purchases, permanent identifiers or customer games were deleted/rewritten. Query review verified scoped predicates and existing account/order indexes; no schema migration.

Published to https://ion.floot.app as 0.35.0 (checkpoint `d5cec0e2-e394-4939-a4fc-667ccbcbac09`, publish job `3fc85f6b-92f2-424f-87a0-218d926556a0`). The full browser suite passed again against production, including phone layout, received-only Empty/incoming/error states, purchase retry without confirming a transaction, direct totals, filtered hold controls and the native engine reset to White.
