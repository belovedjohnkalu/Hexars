# ION 0.46 — Safari authority and consistent appearance

Future Schedule dates, months and years are orange (#ffad5c). Current periods stay white; saved past periods stay green. My Space (IL03) now has a silver/frosted-glass journal icon.

Safari author permissions remain server enforced for edit, move, Redirect and delete. Every registered dev can now moderate Safari, independent of its originally configured owner; generic admin roles and forged browser flags grant nothing. Mixed-author branches remain protected from ordinary authors. Moving preserves original authorship, while duplicating assigns newly added copies to the copier. Home/Chess editing and private Schedule boundaries are unchanged.

Inversion now changes the actual document/body backgrounds and declared light/dark scheme as well as the visible content. AppHead's browser theme color follows the same preference, and installed-web-app status bars are no longer forced black. Portal dialogs and split views stay inverted exactly once. Default remains black. Physical iPhone status-bar behavior, including previously installed OS chrome, is not observable in this environment.

Photo decoding is asynchronous within stable image frames. Stale cloud reads cannot clear a newer account's loading state, publish an old error, or reveal the prior account's data. Existing mutation version checks remain.

Validation: hosted typecheck clean; nine relevant hosted suites passed, covering forged Safari requests for all four protected operations, registered-dev membership, mixed authors, transfer authorship, account-switch races, calendar/leap/timezone behavior, appearance and Schedule privacy. Phone/desktop preview checks passed for orange years/months/days, current/past colors, metadata and real white backgrounds, fullscreen portal inversion and default-theme restoration. Published at https://ion.floot.app. Live fixture checks confirm orange future years/months/days on desktop/phone, and all four anonymous protected Safari operations return 401. Appearance metadata, restoration, reload persistence, portal and split-pane checks run against the live deployment. Settings was moved to Home during verification; tests preserve the current placement and verify manual Controls history through its actual children.

Premium strict audit still reports 32 existing composite-component false positives, zero unresolved owners; no clean static-audit claim. Test fixtures do not create real users or alter customer words. The only live data edit is My Space's requested icon. No Time ledger changes.
