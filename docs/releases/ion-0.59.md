# ION 0.59 — HexDame and Kruzno’s Checkers

Two playable checkers games are added beneath the existing Checkers cloud, IL01A0. Existing Chess organization and user-created content are preserved. Each game has an authoritative cloud rules module, starting-position preview, illustrated rules, complete capture-route selection, a six-level Computer, pass and play, online matches, saved positions, notation, sharing, undo and result sheets.

HexDame uses 61 cells, 16 men per side, global maximum capture, flying kings, deferred captured blockers and end-of-turn promotion. Kruzno uses 91 cells, 12 men per side, six-direction steps, compulsory complete captures and restricted border exits. **Captures take priority over border exits**, as explicitly selected by the user. Kruzno’s Black-first, repetition and no-capture draw conventions are disclosed as ION policies where the publisher is silent. See the [HexDame](../variants/hexdame.md) and [Kruzno](../variants/kruzno.md) source notes.

Game requests retain the existing account/capability permissions, optimistic versions and Postgres persistence. Complete move paths are validated again on the server. A dedicated checkers computer uses iterative alpha-beta; the six C++ chess engines remain unchanged. Matchmaking filters chess/checkers families and owned variants. Both new products inherit the existing shared-work Time price; new legacy proposal rows assert no fixed historical estimate. New shared cloud identifiers belong to dev namespace zero.
