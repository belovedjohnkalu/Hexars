# ION 0.32 — Simpler spaces and affordable discovery

IL09 is Time. Its separate Balance entry (IL090) is removed; Activity (IL091) retains Added, Spent and Balance. Old Balance URLs open Activity, and old IL records remain reserved. Time is now a shared editable home-space hub, using the existing owner authorization, realtime, composer and Controls. The dev can add words/pictures and edit/delete its entries. Financial amounts and journal records remain authoritative server data.

Unaffordable paid entries and their descendants are absent from normal navigation, rules, engine selection, matchmaking selection and Prices. Purchased entries and dev access remain visible. Affordable unpurchased entries appear struck through and route directly to their Time trade page. Locked rules don't ship their text/illustration. Direct unpaid game URLs route to trade/Prices without a redundant intermediate gate. Wallet/catalog events refresh discovery. Saved receipt facts, free features and ledger protections remain intact.

Public and Private label limits are 1 word at the first level, then 2, 4, 8, etc. The limit is an exact arbitrary-precision power of two without a fixed depth ceiling. It counts whitespace-delimited words, not characters or the number of children. Existing labels are not truncated or deleted. Add/rename/copy/move/transfer use the same server policy; moving a branch to a stricter layer can require shorter names. The existing 1,024 immediate-child safety cap is separate and unchanged. Input hints show the current word allowance; no 80-character restriction remains in Public/Private.

Copy review scanned all 187 maintained source files (8,661 source lines at audit time). Removed repeated scope explanations, the duplicated long-name display, redundant product disclosures and the unused static Time hub implementation. Redirect replaces Link in the control, editor, actions and feedback, preserving protocol IDs/ILs. Rule facts, privacy/destructive warnings and financial confirmation terms are preserved.

Architecture changes: one shared feature-discovery policy for server and client; one depth-limit authority for all mutation paths; stable memoized merged cloud data; one bottom-up pass for character weights and descendant counts; linear adjacency construction; 128-entry LRU bounds for layout and camera caches. No host migration, native chess-rule changes or historical-data truncation.

Validation: all 51 existing/new helper spec files passed before the final shared-state fix; the additional mounted-view regression passed, and targeted gate/depth/layout suites passed after refinements. Hosted TypeScript is clean. Preview browser checks covered real Private 1/2/4-word creation, the Public server guard, three Activity totals, hidden unaffordable features, crossed-through affordable trade routing, and dev Time add/edit/delete. A same-account mutation broadcast now updates all mounted views immediately without waiting for realtime. Isolated QA users are retired after checks; no customer costs, purchases or journal records were deleted.
