# ION 0.47 — ChatGPT plugin, Journal icons and paid Schedule

Published at https://ion.floot.app. Plugin installation guide: https://ion.floot.app/chatgpt. The production MCP server is https://ion-chatgpt.9khv8m59km.workers.dev/mcp; select OAuth when adding it as a custom ChatGPT plugin. Account installation/consent and any public-directory review remain ChatGPT-side steps; this release does not claim to have installed or approved a directory listing.

The portable `plugins/ion` package contains schema-validated Agent Plugins manifests and an ION skill. An authenticated user can read a level of their Journal or purchased Schedule and save explicitly requested words through the official MCP SDK. OAuth discovery, automatic client registration, authorization code with S256, audience-bound hashed tokens, single-use codes, rotating refresh tokens, scope enforcement and account-specific revocation are implemented. The connection cannot delete words, spend Time, purchase features, access other accounts or read dev prompts. Existing word/capacity limits, version checks, idempotent save IDs, private workspace selectors, immutable dev identifiers and realtime updates are reused. Normal ION sign-in still goes to Home; the plugin has its own explicit consent/sign-in surface.

The dedicated Cloudflare Worker serves discovery and fixed API forwarding; ION's website, accounts and authoritative database remain on Floot. Existing Cloudflare `hexars` is unchanged. No secrets or new database bindings were needed. The gateway normalizes AWS's remapped authentication challenge and rejects upstream redirects without following them. Raw request/token logging is disabled. See docs/integrations/chatgpt.md and cloud/migrations/047-chatgpt-schedule.sql.

Schedule is `feature:schedule`, using the existing dev estimate/revision/publication, buyer division, quote and purchase system. Its estimate and publication are deliberately unset until the dev supplies them through Wallet → Estimates → Schedule. Existing products were not repriced; no purchase, earning or financial entry was created. Non-dev accounts cannot open Schedule without a purchase, including through direct links or MCP; unpriced/unaffordable Schedule branches are hidden, affordable unpurchased ones have the canonical gate. Dev access stays free. Stored entries remain private and intact, including from other devs. Historical feature quotes and purchases are unchanged. New Schedule allocations use the current product count when its estimate is published; existing features keep their approved allocations until an explicit free-work revision is published.

Following the user's subsequent styling request, IL03 Journal shows an open journal and pen, and IL01 Hexagonal Chess shows a king in a hexagon. Both match the existing silver, fine blue edge-light and black icon family. They replace the earlier literal journal photo; provenance for both stages is retained in cloud/assets/ion-0.47-artwork.json. The user's live Journal rename is reflected in its private root, sign-in prompt and navigation. Root IDs, permanent ILs, user words and Home placement are preserved.
