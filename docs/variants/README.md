# Historical rules references

Gliński is implemented and tested; see [Gliński conventions](glinski.md). The remaining variants require independent research before implementation.

Starting references:

- [Hexagonal chess overview](https://en.wikipedia.org/wiki/Hexagonal_chess), including the six historical variants.
- [Dave McCooey’s hexagonal chess](https://www.chessvariants.com/hexagonal.dir/hexagonal.html).

Each future module must record original rule diagrams, notation, special rights, and independent fixtures. In particular, Wellisch's exact check, elimination and victory rules must be established before its multiplayer result/search implementation.
