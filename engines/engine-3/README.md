# Defensive 1.0.0

Threat-first paranoid alpha-beta with king-danger and exposed-material evaluation. Wellisch opponents form an adversarial coalition.

This is an independent C++ executable. Only rules, serialization and protocol ABI are shared. Supports all six variants, bounded iterative search, legal fallback and native validation.

Build from repository root: `npm run build:defensive` (or append `-- --cloud` on Linux x64). `npm run test:search` verifies both new searches, including complete games. See [release details](../../docs/ion-independent-engines-release.md).
