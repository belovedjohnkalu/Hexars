# Materialist 1.0.0

MTD(f) with a bounded, history-aware transposition table, exchange resolution and material-led evaluation. Wellisch uses a conservative opponent-coalition model.

An independent executable and search implementation; only protocol ABI and authoritative rules are shared. Supports all six variants. Build: npm run build:materialist. Add -- --cloud on Linux x64 for a static binary. See [release verification](../../docs/ion-materialist-unconventional-release.md).
