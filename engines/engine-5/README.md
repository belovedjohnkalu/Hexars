# Unconventional 1.0.0

PUCT tree search with seeded, guided sampled rollouts, novelty/development priors and material-safety evaluation. Each actual player has its own reward, including Wellisch army takeovers and same-turn promotions.

An independent executable and search implementation; only protocol ABI and authoritative rules are shared. Supports all six variants. Build: npm run build:unconventional. Add -- --cloud on Linux x64 for a static binary. See [release verification](../../docs/ion-materialist-unconventional-release.md).
